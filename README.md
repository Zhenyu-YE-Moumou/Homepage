# Math PhD academic homepage

这是一个适用于 GitHub Pages 的单页学术主页。整个网站只需要 `index.html`：内容和样式都在同一个文件中，不需要安装软件、框架或运行构建命令。双击 `index.html` 即可在电脑上预览。

## 在 GitHub 上发布

1. 登录 GitHub，新建一个名为 `你的用户名.github.io` 的仓库（用你的真实 GitHub 用户名替换）。使用 GitHub Free 时，请选择 Public。
2. 将本压缩包中的 `index.html` 上传到仓库根目录（不是上传整个压缩包），提交更改。
3. 打开仓库的 **Settings → Pages**。在 **Build and deployment → Source** 选择 **Deploy from a branch**，再选择 `main` 分支和 `/(root)`，点击 **Save**。
4. 等待 GitHub Pages 完成发布，然后访问 `https://你的用户名.github.io/`。首次发布或更新可能需要几分钟。

如果你使用其他仓库名，网站地址通常是 `https://你的用户名.github.io/仓库名/`。GitHub 官方说明：https://docs.github.com/en/pages/quickstart

## 修改主页

在 GitHub 仓库中打开 `index.html`，点击右上方铅笔图标，修改文字后点击 **Commit changes**。GitHub Pages 会自动重新发布。

- 替换 `Your Name`、学校和个人简介等占位内容。
- 在 Research interests 中修改研究方向。
- 按每个部分的中文注释添加论文、讲座和教学条目。请删除或替换方括号里的提示文字。
- 若要添加 CV，上传 `cv.pdf` 到仓库根目录，再按 CV 部分的注释添加链接。
- 邮箱建议按 Contact 部分的注释改成 `mailto:` 链接。

你也可以在电脑上编辑该文件，完成后重新上传到仓库。请只填写你自己的真实信息。
